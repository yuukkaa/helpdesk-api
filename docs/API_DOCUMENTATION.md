# Документация API и Таблица Тест-кейсов — Веб-сервис технической поддержки (Help Desk)

## 1. Общие сведения
- **Базовый URL API:** `http://localhost:8000/api` (также поддерживается версионированный префикс `http://localhost:8000/api/v1`)
- **Формат обмена данными:** JSON (`Accept: application/json`, `Content-Type: application/json`)
- **Аутентификация:** Bearer-токен Laravel Sanctum (`Authorization: Bearer <token>`)
- **Роли в системе:**
  - `client` — клиент (создаёт заявки, ведёт переписку по своим обращениям, читает опубликованные статьи базы знаний);
  - `support` — специалист техподдержки (видит все заявки, берёт заявки в работу на себя, меняет статусы своих заявок, добавляет служебные заметки и теги, управляет статьями БЗ, просматривает статистику и экспортирует CSV);
  - `admin` — администратор (полные права, управление категориями и пользователями, назначение любых исполнителей, удаление заявок).
